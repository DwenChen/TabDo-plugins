# 差异比较

面向 TabDo `session-v1` 规范实现的本地离线差异比较插件。所有解析、比对与报告生成均在本机完成，不依赖外网、不加载远程字体，也不常驻后台。

## 核心能力

- **文本对比**：双栏并排与统一高亮视图、行级与字符级内联差异、仅显示差异折叠、忽略空白/大小写、上一处/下一处跳转、左右互换、手动保存对比历史（持久存储于插件私有 `dbStorage`）与 HTML 差异报告导出。
- **图片对比**：支持左右对比、滑动对比、淡化对比与像素差异高亮四种模式，自动尺寸对齐、缩放/拖拽/适应窗口、支持粘贴截图与拖入文件，并可将对比结果另存为 PNG。
- **文件夹对比**：基于白名单授权的安全本地目录递归扫描与同步目录树浏览，支持后台并发可控的内容指纹校验（SHA-256 及文本/OOXML 规范化指纹），支持仅差异过滤、关键词搜索、内联点击查看任意文件差异，并可导出 HTML 或 CSV 差异报告。
- **Word / Excel / PDF / PPT 对比**：原生离线解析 `.docx`、`.xlsx` / `.csv` / `.tsv`、`.pdf`、`.pptx`，支持工作表/幻灯片/页级导航、表格列顺序调整识别、并排与差异高亮切换，以及 HTML 报告导出。

## 指令入口

- 普通文本指令：`差异比较`
- 文件 / 文件夹 / 图片匹配指令：`差异比较`（选中 1–2 个文件、文件夹或图片直接进入对应对比视图）

## 生命周期与隐私说明

- 声明并实现 `lifecycle: session-v1`，统一使用 `window.tabdo` 与 `window.tabdo.lifecycle`。
- 退出会话时自动中止未完成的扫描、哈希计算和像素比对任务，释放事件监听、计时器、对象 URL、画布缓冲与白名单路径缓存。
- 文本历史保存与差异报告/图片导出通过 `lifecycle.runTask` 登记为有限必要任务，采用临时文件写入与原子替换；退出时保留用户主动保存的私有 `dbStorage` 历史数据。
- 声明支持用户可控的标题栏「临时常驻」开关（默认关闭）。
